# ADR 0005：框架可复用，但不能成为控制边界

## 状态

已接受。

## 背景

智能体生态中有 Spring AI、LangGraph、OpenAI Agents SDK、MCP 以及公司内部平台等多种能力。它们可以降低开发成本，但也可能隐藏模型输入输出、工具调用和运行状态，使排错变难。

本项目又存在内外开发差异：外部开发环境不能访问公司内网智能体平台，内部环境又需要接入公司现成平台。

## 决策

本项目将 Tool Contract、Agent Event、Guardrails、Run State 和审计日志作为自有控制边界。

框架只能作为实现细节使用，例如：

- 用 Spring AI 辅助 Java 侧模型调用或工具 schema 转换。
- 用 MCP adapter 暴露工具给内部平台。
- 未来用图式框架实现复杂排座状态机。

任何框架都不能绕过本项目的权限、结构化校验、人工确认和审计。

## 后果

优点：

- 内外环境可切换。
- 公司平台细节变化时影响可控。
- 智能体问题可追溯。
- 未来可以逐步替换实现框架。

代价：

- 初期需要自己维护一层轻量 Harness 契约。
- 不能完全依赖框架自动魔法。

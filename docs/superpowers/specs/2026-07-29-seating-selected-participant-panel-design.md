# 排座模式选中人员信息窗设计

## 1. 目标

排座模式里，用户需要在不遮挡画布的情况下查看人员完整信息，并且拖拽人员时画布保持清爽。本次调整把“鼠标悬浮座位看详情”改为“选中人员后在画布左上角查看详情”。

## 2. 范围

本期包含：

- 排座模式新增可收缩的人员信息悬浮窗。
- 鼠标移动到座位上不再弹出 Element Plus tooltip。
- 已排座位、待排列表人员、拖拽开始都会选中对应人员并展示信息窗。
- 颜色分组说明固定在画布左下角，不再拖动。
- 拖拽人员时使用统一的人名拖拽预览。
- 拖拽经过座位时只保留高亮状态，不展示提示文字。

本期不包含：

- 改动人员编辑后端逻辑。
- 改动排座保存、区域保存或布局保存接口。
- 在布局模式或区域模式展示人员信息窗。

## 3. 交互设计

### 3.1 人员信息悬浮窗

显示条件：

- 仅排座模式显示。
- 当前有选中人员时显示。
- 点击画布空白处取消选中并关闭。

位置和状态：

- 默认固定在画布左上角。
- 收缩展开方式参考颜色说明组件：完整卡片加右侧小按钮。
- 收缩后只保留一个小标签，点击后展开。

内容：

- 固定信息：姓名、工号、状态、座位编号。
- 动态信息：展示所有非空扩展字段。
- 多条记录：使用通用的“记录 1 / 记录 2”分组，不写死会议业务名称。
- 草稿排座模式下提供编辑入口。

### 3.2 座位 hover

- 移除座位上的 `el-tooltip` 和大块悬浮信息。
- 座位内部仍显示 `第m排n` 和人员姓名。
- 完整人员信息只从人员信息窗读取。

### 3.3 颜色说明

- 颜色说明固定到画布左下角。
- 不再支持拖动。
- 保留展开、收缩和颜色修改能力。
- 颜色选择弹窗关闭顺序保持一致：收缩前先关闭颜色选择弹窗。

### 3.4 拖拽预览

- 待排列表和画布已排人员拖拽时使用统一的轻量预览。
- 预览形态为一个包含姓名和工号的白色浮层，视觉上像拖着一个人员姓名。
- 拖拽经过目标座位时，画布只显示目标高亮，不显示额外文字提示。

## 4. 验收标准

- 鼠标移到座位上不会弹出人员详情 tooltip。
- 点击待排人员后，画布左上角出现人员信息窗。
- 拖动待排人员前能通过该信息窗看到完整人员信息。
- 点击已排人员座位后，信息窗展示该人员的完整信息。
- 点击画布空白处，信息窗关闭。
- 颜色说明固定在左下角且仍可收缩。
- 拖拽人员时的鼠标拖拽预览展示姓名和工号。
- 拖拽目标座位没有文字提示，只保留高亮。

# 会议排座工作台增强设计

## 1. 目标

本次增强面向会议排座工作台，解决秘书在会议草稿阶段继续调整人员字段、人员信息、会议布局、区域预留、座位编号、颜色分组和 Excel 导出的需求。

设计目标如下：

- 单个添加人员时可以新增人员信息列，不再只能通过 Excel 导入扩展字段。
- 草稿版本的待排列表和全部列表中可以编辑人员信息。
- 会议草稿中可以编辑会议自己的布局快照，不影响原场馆模板，也不丢失已经添加的人员信息。
- 座位在会议页和导出中动态显示为 `m排n`，并在画布左右两侧显示排号。
- 支持按人员动态字段给已排人员座位着浅色分组。
- 支持选中一组座位后创建“嘉宾”等区域标记，视觉上类似 Excel 合并单元格。
- 导出统一只保留 Excel，删除 PDF 相关入口和逻辑。

## 2. 范围

### 2.1 本期包含

- 会议排座页新增 `排座模式`、`布局编辑模式`、`区域标记模式`。
- 草稿版本允许编辑会议布局；发布版本只读。
- 会议布局编辑复用场馆模板布局编辑器的核心交互，并增加会议专属保护规则。
- 区域标记支持不规则座位集合，并以合并区域中心标签展示。
- 人员新增和人员编辑支持新增动态字段。
- 人员编辑支持单记录表单和多记录表格。
- 座位编号在前端展示和后端导出中使用同一规则。
- 画布左右两侧显示排号标识。
- 按动态字段对已排人员座位进行浅色分组。
- Excel 导出包含人员名单和排座图。
- 移除 PDF 导出按钮、接口和生成逻辑。

### 2.2 本期不包含

- 自动排座算法。
- 分组颜色的手工配色配置。
- 区域标记自动根据部门或批次匹配人员。
- 对已发布版本进行编辑。
- 修改人员工号。
- 将区域标记作为人员记录导入或导出到人员名单。

## 3. 工作台模式

会议排座页顶部工具栏增加三段模式切换。

### 3.1 排座模式

排座模式是默认模式，保留现有能力：

- 从待排列表拖拽人员到空座位。
- 在两个已排人员之间交换座位。
- 双击或拖回待排列表释放人员。
- 标记临时不来或恢复出席。
- 新增人员、批量导入、保存草稿、发布版本。
- 查看排号、座位编号、颜色分组和区域标记。

排座模式不允许移动、缩放、删除或新增布局元素。

### 3.2 布局编辑模式

布局编辑模式只在草稿版本可用。进入后可以像模板布局编辑页一样：

- 框选空白区域新增座位、门、墙、桌子、摄像、舞台、显示屏等元素。
- 移动元素。
- 缩放元素。
- 修改元素显示名称、填充色、边框色。
- 删除元素。
- 撤销和重做布局编辑。

会议布局编辑的是 `t_meeting_elements` 中的会议独立布局快照，不修改场馆模板。

防误删规则：

- 删除空座位：直接删除。
- 删除已排人员座位：弹窗确认，确认后人员退回待排列表。
- 删除区域标记座位：弹窗确认，确认后这些座位从区域标记中移除；如果标记没有剩余座位，则删除整个标记。
- 删除非座位元素：没有占用关系时直接删除。
- 移动或缩放元素导致越界或重叠：禁止落位，保留冲突提示。

发布版本不能进入布局编辑模式。

### 3.3 区域标记模式

区域标记模式只在草稿版本可用，用于把一组座位合并成一个预留区域，例如“嘉宾”“部门一”“获奖人员”。

区域标记占用座位。被标记座位不能再拖入具体人员；如需细排人员，必须先取消或调整区域标记。

创建标记流程：

1. 点击“新建标记”。
2. 输入标记名称。
3. 选择浅色填充，默认提供浅黄、浅蓝、浅绿、浅粉、浅紫、浅橙、浅青。
4. 通过框选和点选选择座位。
5. 确认保存。

选座方式：

- 拖拽矩形：把矩形范围内实际存在的空座位加入当前标记草稿。
- 单击座位：切换选中或取消选中。
- `添加座位 / 移除座位` 二段切换：在移除模式下，框选或单击会从当前草稿中扣掉座位。
- 可以重复多次框选和点选，支持不规则或分散的座位集合。

保存校验：

- 标记名称不能为空。
- 至少选择一个座位。
- 已排人员座位不能加入。
- 已被其他标记占用的座位不能加入。
- 锁定、禁用或非座位元素不能加入。

视觉展示：

- 被标记座位统一显示浅色覆盖。
- 单个座位上不重复显示标记名称。
- 系统在选中座位集合的视觉中心绘制一个浮层标签，例如 `嘉宾`。
- 如果中心点落在空洞或非座位区域，标签吸附到距离中心最近的已选座位区域中间。
- 如果同一个标记包含多块互不连通的区域，每个连续区域各显示一个居中标签，改名、改色和删除仍然作用于同一个标记。

编辑已有标记：

- 点击标记颜色区域或中心标签，选中整个标记。
- 右侧面板展示标记名称、颜色、包含座位数。
- 支持改名、改色、继续添加座位、移除部分座位、删除整组。
- 删除整组后，座位恢复为空座位。

## 4. 人员字段和人员编辑

### 4.1 单个添加时新增列

单个添加人员弹窗保留工号、姓名和已有动态字段，并增加“添加列”区域。

新增列交互：

- 点击“添加列”后新增一行：`列名`、`该人员的值`、删除按钮。
- 可以一次新增多列。
- 新增列名保存后注册为当前会议的动态字段。

保存校验：

- 工号必填，继续使用现有格式规则。
- 工号在当前会议中忽略大小写唯一。
- 姓名必填。
- 新增列名必须非空。
- 新增列名不能和已有字段重名，也不能和本次新增的其他列重名。
- 新增列对应的本人员值必须非空。
- 已有动态字段仍然可填可不填。

保存成功后：

- 后端注册新增字段。
- 新增人员保存对应字段值。
- 其他已存在人员的新字段值为空。
- 前端刷新工作台，新增字段出现在人员卡片、编辑弹窗、分组下拉和导出列中。

### 4.2 人员列表按钮设计

草稿版本的待排列表和全部列表中，每个人员卡片右侧显示三个统一图标按钮：

- 编辑。
- 临时不来或恢复出席。
- 移出会议。

按钮使用同一尺寸、同一视觉风格，鼠标悬浮显示文字说明。卡片主体保留姓名、工号和字段摘要，避免按钮文案挤占内容。

发布版本人员列表只读，不显示编辑、临时不来和移出会议按钮。

### 4.3 编辑人员

点击编辑后打开“编辑人员”弹窗。

编辑规则：

- 工号只展示，不允许修改。
- 姓名可修改，不能为空。
- 动态字段可修改。
- 如果在编辑弹窗内新增列，新增列名和值仍然必须非空。

多记录规则：

- 如果人员只有一条动态记录，编辑弹窗使用普通表单展示动态字段。
- 如果同一人员有多条动态记录，姓名仍然统一修改；动态字段按记录表格展示，每条记录一行，用户逐条修改字段值。
- 保存时保留记录顺序。

保存成功后：

- 刷新人员列表。
- 刷新画布上已排人员显示。
- 刷新颜色分组和图例。

## 5. 座位编号和排号

### 5.1 编号规则

系统提供统一的座位编号计算器，前端和后端导出使用同一规则：

- 只统计 `SEAT` 元素。
- 按座位起始网格行从上到下排序。
- 只有存在座位的网格行才算一排。
- 空行、舞台、门、墙、桌子、摄像、显示屏等非座位元素不参与排号。
- 同一排内按座位起始列从左到右编号。
- 座位显示名为 `m排n`。

示例：座位出现在画布第 3 行、第 5 行、第 8 行，则它们分别对应第 1 排、第 2 排、第 3 排。

### 5.2 会议画布展示

座位内部显示：

- 空座：显示 `m排n`。
- 已排人员：显示 `m排n` 和人员姓名。
- 区域标记占用座位：单个座位不显示文字，由合并区域中心标签显示标记名称。

鼠标悬浮卡片显示：

- 座位编号 `m排n`。
- 人员姓名和工号。
- 动态字段摘要。
- 锁定状态。
- 当前颜色分组字段和值。
- 区域标记名称和座位数量。

会议布局编辑时新增、删除、移动座位后，编号立即重新计算。

### 5.3 左右排号标识

画布左右两侧各显示一列排号标识，例如 `1排`、`2排`。

排号标识规则：

- 只在有座位的行旁显示。
- 不占用画布网格。
- 不影响元素点击、拖拽、框选和右键平移。
- 随画布缩放和滚动对齐座位行。
- 字体保持可读范围，不能随缩放变得过小。

## 6. 颜色分组

排座页工具栏增加“颜色分组”下拉。

规则：

- 默认不按字段着色。
- 可选字段来自会议动态字段。
- 工号和姓名不作为颜色分组字段。
- 选择字段后，画布中已排人员座位按该字段的主值着色。
- 同一个字段值使用同一种浅色。
- 空值不着色，保留座位原本颜色。
- 颜色只影响当前视觉展示和本次导出，不修改人员数据或座位元素本身颜色。

预置色：

- 浅黄、浅蓝、浅绿、浅粉、浅紫、浅橙、浅青等浅色。
- 文字统一使用深色，保证可读。
- 颜色数量不够时循环使用，但图例仍按值区分。

图例：

- 工具栏附近展示一个小图例入口。
- 默认展示前几项，例如前 5 项。
- 超出后可展开查看完整图例。

导出排座图 Excel 时，应用当前选择的颜色分组。

## 7. Excel 导出

系统只保留 Excel 导出，删除 PDF 相关前端入口、后端接口和 PDF 生成逻辑。如果 PDF 依赖只用于导出 PDF，也同步清理。

导出入口：

- 导出人员名单 Excel。
- 导出排座图 Excel。

草稿和发布版本都支持导出。草稿导出文件名包含“草稿”；发布版本导出文件名包含版本名称。

### 7.1 人员名单 Excel

列结构：

- 工号。
- 姓名。
- 所有动态字段。
- 座位。

座位列使用 `m排n`。未排座人员座位列为空。

区域标记不出现在人员名单中，因为区域标记不是参会人员。

### 7.2 排座图 Excel

排座图 Excel 包含：

- 排座图 sheet。
- 座位明细 sheet。

排座图 sheet：

- 按画布网格生成。
- 座位编号使用动态 `m排n`。
- 已排人员单元格显示 `m排n` 和姓名。
- 区域标记按视觉合并效果展示：同一连续区域尽量合并为一个显示区域，中心显示标记名称。
- 应用当前颜色分组。
- 非座位元素显示元素名称。

座位明细 sheet：

- 座位编号。
- 占用类型：空座、人员、区域标记。
- 人员姓名或标记名称。
- 人员工号。
- 动态字段。

## 8. 数据和接口设计

### 8.1 会议布局保存

新增会议草稿布局保存能力，保存 `t_meeting_elements` 的完整布局集合。

保存前校验：

- 只能保存当前用户拥有的会议。
- 只能保存草稿版本对应的会议布局。
- 画布行列数不小于最小值。
- 元素必须在画布边界内。
- 元素不能重叠。
- 元素类型只能是 `SEAT` 或 `GENERIC`。
- 删除座位前必须处理其人员或区域标记占用关系。

保存策略：

- 会议布局使用完整集合替换。
- 人员占用和区域标记占用在同一事务内清理或重建。
- 不影响原场馆模板。

### 8.2 区域标记

区域标记复用现有排座占用项模型，使用 `PlanItemType.RESERVED` 表示。

字段映射：

- `item_type = RESERVED`。
- `participant_id = NULL`。
- `label = 标记名称`。
- `background_color = 标记颜色`。
- `text_color = 深色文字`。
- `targetElementIds = 被标记座位 ID 集合`。

同一个区域标记可以关联多个座位。保存时必须确保同一座位不会同时被人员和区域标记占用。

### 8.3 人员编辑

新增人员更新接口。

请求内容：

- 姓名。
- 动态记录列表。
- 本次新增字段和值。

后端规则：

- 工号不可更新。
- 姓名不能为空。
- 新增字段名和值不能为空。
- 新增字段名不能和已有字段重名。
- 多记录按请求顺序保存。
- 更新在事务内完成，字段注册、人员信息更新、记录更新保持一致。

### 8.4 导出

Excel 导出支持当前草稿和指定发布版本。

请求参数包含：

- 导出类型：人员名单或排座图。
- 版本 ID，可为空；为空表示当前草稿。
- 颜色分组字段，可为空。

后端根据工作区快照或当前草稿计算座位编号、区域标记合并展示和人员字段列。

## 9. 错误处理和提示

- 新增列名为空：提示“请输入列名”。
- 新增列值为空：提示“请填写该人员在新增列中的值”。
- 字段重名：提示“该列已存在，请使用其他列名”。
- 编辑人员保存失败：保留弹窗内容，不清空用户输入。
- 区域标记未选择座位：提示“请选择至少一个座位”。
- 区域标记选择了已占用座位：跳过不可用座位，并提示“部分座位已被人员或标记占用”。
- 删除已排人员座位：弹窗说明人员将退回待排列表。
- 删除区域标记座位：弹窗说明对应标记范围将缩小。
- 草稿有未保存变更时导出：先保存草稿，保存失败则不导出。

## 10. 验证方案

### 10.1 前端测试

- 单个添加人员支持新增列，并校验列名和值非空。
- 新增列不能与已有字段或本次新增列重名。
- 人员卡片三个操作按钮样式统一，发布版本不显示编辑按钮。
- 编辑人员弹窗中工号只读，姓名和动态字段可编辑。
- 多记录人员使用记录表格编辑。
- 三段模式切换只在草稿版本开放布局编辑和区域标记。
- 区域标记支持框选、点选、添加、移除、不规则区域和多块区域。
- 区域标记中心标签不在每个座位重复显示。
- 座位编号按有座位的行从上到下、同排从左到右计算。
- 空座显示 `m排n`，已排人员显示 `m排n` 和姓名。
- 左右排号标识只出现在有座位的行。
- 颜色分组按动态字段着色，空值不着色。
- 前端不再展示 PDF 导出入口。

### 10.2 后端测试

- 人员更新接口不允许修改工号。
- 人员更新接口支持新增字段和多记录保存。
- 新增字段注册和人员记录写入在同一事务中完成。
- 会议布局保存不影响场馆模板。
- 删除已排人员座位会释放人员占用。
- 删除区域标记座位会缩小标记范围或删除空标记。
- 同一座位不能同时被人员和区域标记占用。
- 座位编号计算与前端规则一致。
- 草稿和发布版本均可导出人员名单 Excel。
- 草稿和发布版本均可导出排座图 Excel。
- PDF 导出接口被移除。

### 10.3 回归测试

- Excel 导入仍然可以注册动态字段。
- 现有拖拽排座、交换座位、移回待排列表继续可用。
- 临时不来人员不能排座。
- 发布版本仍然只读。
- 发布版本恢复草稿逻辑不破坏新增字段和区域标记。
- 场馆模板编辑页不受会议布局编辑改造影响。

## 11. 验收标准

- 用户可以在单个添加人员时新增列并保存人员。
- 用户可以在草稿待排列表和全部列表中编辑人员姓名和动态字段。
- 用户不能修改人员工号。
- 用户可以在会议草稿中增删改布局元素，且不会影响场馆模板。
- 用户删除已排人员座位时会看到确认提示，确认后人员回到待排列表。
- 用户可以创建不规则区域标记，并在画布中看到合并区域中心标签。
- 被区域标记占用的座位不能再安排具体人员。
- 画布左右两侧显示准确排号。
